## Sobre o projeto

**SECRETO** e um gerenciador de senhas pessoal que funciona 100% offline. Guarda, organiza e consulta suas senhas com seguranca e privacidade total. Nenhum dado sai do seu aparelho.

---

## Funcionalidades

- Dupla protecao por senha mestra
- Cadastro e login
- Armazenamento de senhas (site, usuario, senha)
- Gerador de senhas fortes (14 caracteres)
- Busca instantanea
- Visualizacao sob demanda
- Exclusao protegida
- Alteracao de credenciais

---

## Privacidade

| Aspecto | Status |
|---|---|
| Dados para servidores | Nunca |
| Rastreamento | Nenhum |
| Internet | Nao precisa |
