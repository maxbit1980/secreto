🌐 Publicar App

Links gratuitos para hospedar seu projeto

🚀 Hospedagem Web (PWA)

Publique seu arquivo HTML como site e permita que os usuários instalem no celular como app. Recomendado para começar.

🐙 GitHub Pages Grátis
Hospedagem direta do seu repositório GitHub. Simples e confiável.
pages.github.com
🎯 Netlify Drop Mais Fácil
Arraste a pasta e pronto! Online em segundos sem configurar nada.
app.netlify.com/drop
▲ Vercel Grátis
Deploy automático conectado ao GitHub. Ótimo para projetos modernos.
vercel.com/new
☁️ Cloudflare Pages CDN Global
Hospedagem com rede global rápida em qualquer região do mundo.
pages.cloudflare.com
⚡ Tiiny Host 1 Clique
Upload direto do HTML sem criar conta. 1 site grátis.
tiiny.host/pt-br
📱 Distribuir APK (Android)

Publique o APK gerado para download direto ou em lojas alternativas à Google Play.

📦 Amazon Appstore Loja
Loja oficial para dispositivos Amazon (Fire TV, Kindle, etc).
developer.amazon.com/apps-and-games
🤖 F-Droid Open Source
Loja focada em apps de código aberto, sem taxas nem rastreamento.
f-droid.org
🧊 IzzyOnDroid Repo F-Droid
Repositório adicional para o F-Droid, aceita mais tipos de apps.
apt.izzysoft.de/fdroid
💡 Passo a passo recomendado
  1. Renomeie seu arquivo para index.html
  2. Coloque em uma pasta junto com o manifest.json e ícones
  3. Acesse app.netlify.com/drop e arraste a pasta
  4. Você receberá um link público em segundos — compartilhe!
  5. No celular, o navegador oferecerá "Adicionar à tela inicial" → vira um app
